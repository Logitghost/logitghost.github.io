Neural Probabilistic Language Model

makemore-style, from scratch — PyTorch
PyTorch

Started with a bigram baseline and worked up to a proper neural MLP based on the Bengio 2003 paper, with learned character embeddings. Built the whole data pipeline myself — 4-character context window, a 27×6 embedding space, 80/10/10 split — and trained a 2-layer MLP (24→500→27) with tanh activations. Watching the loss actually drop below the bigram baseline was the first time this stuff felt real instead of theoretical.

Rain Prediction using SVM

Australia Weather Dataset — ~145K rows
SVM

Predicting next-day rainfall taught me more about missing data than about rain. Clustered locations by climate with KMeans so I could impute within similar climate groups instead of blindly filling the whole column, capped outliers with IQR, and balanced classes with SMOTE before training an SVM with an RBF kernel. Landed at 83% accuracy and a 0.65 F1-score — the imputation strategy mattered more than the model.

Telco Customer Churn Prediction

26-feature telecom dataset
Classification

Engineered features like charge-per-month ratio and tenure buckets, then benchmarked four classifiers — Logistic Regression, Decision Tree, Random Forest, and Gradient Boosting — under class-weighting to handle the churn imbalance. Random Forest came out on top with a 0.66 F1-score. Contract type, tenure, and monthly charges turned out to be the strongest churn signals across every model.
